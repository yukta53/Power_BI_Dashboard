# Power-BI-Dashboard
# 📊Employee HR Analytics Dashboard

# Project Overview
This project is an interactive # Employee HR Analytics Dashboard # built using Power BI to analyze, and visualize key workforce metrics, employee distribution, salaries, and performance.

# 🔍 Dashboard Sections & Visualizations
The dashboard is structured into the following key analytical sections:

**1. Departmental Analysis**
   **Department Employee Count:** A bar chart showing the distribution of employees across various departments (Finance, Marketing, Sales, IT)[cite: 1].
   **Department Salary:** A bar chart visualizing the sum of salaries allocated across different departments[cite: 1].

**2. Geographical & Demographic Insights**
   **Employee by City:** A horizontal bar chart displaying employee distribution across multiple cities (Pune, Mumbai, Delhi, Bangalore, Hyderabad)[cite: 1].
   **Gender Distribution:** A donut chart showing the breakdown of employees by gender (Female vs. Male)[cite: 1].

**3. Workforce Status & Performance**
   **Employee Status:** A pie/donut chart tracking active vs. resigned employees (e.g., 90% Active, 10% Resigned)[cite: 1].
   **Performance Distribution:** A bar chart illustrating the count of employees grouped by their performance ratings[cite: 1].
   **Average Salary by Job Role:** A bar chart comparing average salary levels across roles (Finance, Team Lead, Senior Developer, Marketing)[cite: 1].

**4. Filters & Slicers**
   **Department Slicer:** Quick selection buttons for filtering data by department (Finance, IT, Sales, HR, Marketing)[cite: 1].
   **City & Gender Filters:** Interactive dropdown and checkbox filters to drill down data by location and gender[cite: 1].
